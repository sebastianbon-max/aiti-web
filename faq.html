Todo lo que necesitás saber sobre aiTi

General

aiTi es una plataforma web para gestión integral de infraestructura IT. Permite administrar inventario de equipos de red, backups de configuraciones, direccionamiento IP (IPAM), terminal SSH/Telnet, servicios de internet, telefonía y mucho más. Todo desde una interfaz web unificada, on-premise o en nube, y multi-área.

Para equipos de IT de organizaciones medianas y grandes: áreas de Redes, Telefonía, Soporte, Infraestructura. Ideal para empresas, organismos públicos, universidades y cualquier entidad que gestione equipos de red y necesite trazabilidad, backups automáticos y control de acceso por área.

Cualquier equipo de infraestructura IT: routers, switches, firewalls, access points, servidores, PCs, impresoras, centrales telefónicas, UPS, teléfonos IP, gateways VoIP, NAS, y accesorios (SFP, power injectors, etc.). El sistema es completamente configurable en tipos, marcas y modelos.

Instalación y Requisitos

Un servidor Windows (10 Pro 64-bit o Server 2022) con al menos 4 GB RAM, 20 GB de disco y acceso a la red LAN. No se requieren dependencias externas: todo viene incluido en el instalador. La instalación tarda aproximadamente 10 minutos.

Sí. Podés instalar aiTi en un servidor Windows en la nube (Azure, AWS, etc.) y conectarlo a tu red mediante VPN. De esta forma obtenés alta disponibilidad sin invertir en hardware propio. Los módulos que se conectan a equipos (backups SSH, terminal, monitoreo) necesitan acceso a la LAN del cliente.

No. El instalador incluye y configura automáticamente la base de datos de alto rendimiento. No es necesario instalar ni administrar nada adicional.

Desde cualquier navegador web en la red local, ingresando la dirección del servidor (ej: https://sgir.empresa.local). El acceso es via HTTPS con certificado SSL incluido. Compatible con Chrome, Firefox, Edge y Safari.

Las actualizaciones se aplican manualmente ejecutando un script que descarga la última versión, aplica cambios en la base de datos y reinicia los servicios. El proceso tarda menos de 2 minutos y no requiere reinstalación.
Licenciamiento

aiTi usa licencia perpetua (pagás una vez, usás para siempre). La licencia se vincula a un servidor específico y define los módulos habilitados y los límites de recursos (cantidad de equipos, usuarios, sitios y grupos).

Después de los 30 días de evaluación, el sistema sigue funcionando en modo lectura (podés consultar datos pero no crear/editar). Para seguir operando, necesitás activar una licencia comercial. Tus datos nunca se pierden.

Sí. Podés empezar con los módulos que necesitás y agregar más en cualquier momento. Solo se genera una nueva licencia con los módulos adicionales, sin reinstalar ni perder datos.

La licencia perpetua incluye actualizaciones del primer año. Después, las actualizaciones y soporte técnico se contratan por separado con un plan anual opcional.
Funcionalidades

Cualquier marca. El sistema es agnóstico al fabricante: Cisco, Fortinet, MikroTik, HP/Aruba, Juniper, Ubiquiti, TP-Link, Huawei, etc. Los catálogos de tipos, marcas y modelos son completamente configurables. Para backups SSH funciona con cualquier equipo que acepte conexión SSH o Telnet.

El sistema se conecta a cada equipo via SSH o Telnet usando credenciales encriptadas, ejecuta los comandos configurados (ej: "show running-config") y almacena la salida como backup. Se programan automáticamente (diario, semanal, etc.) y cada vez que hay un backup nuevo, se compara automáticamente con el anterior: si detecta cambios que nadie registró, genera una alerta y queda pendiente de revisión. También puede ver el diff visual completo entre cualquier par de backups.

El sistema permite que múltiples equipos de trabajo (Redes, Telefonía, Soporte, etc.) operen de forma aislada dentro de la misma instalación. Cada área ve solo sus equipos, usuarios y módulos habilitados. Un usuario puede pertenecer a más de un área y cambiar entre ellas sin cerrar sesión.

Sí. El módulo de importación masiva permite cargar equipos, sitios, servicios, personas y contactos desde archivos Excel. Incluye vista previa antes de importar, validación de datos y detección de duplicados.
Seguridad

Sí. aiTi es on-premise o en nube propia: tus datos nunca dependen de servidores de terceros. Las credenciales SSH se almacenan encriptadas, el acceso es via HTTPS, y el sistema incluye auditoría completa de todas las acciones, bloqueo por intentos fallidos y control de sesiones activas.

El sistema tiene 4 niveles de acceso: administrador general (configuración y gestión completa), administrador de área (CRUD dentro de su grupo), operador (crear equipos, ejecutar backups) y monitor (solo lectura). Cada rol ve únicamente lo que le corresponde.

Sí. Toda acción crítica (crear, editar, eliminar equipos, ejecutar backups, cambios de configuración) queda registrada con usuario, fecha, hora e IP. Los logs de auditoría son consultables desde el sistema con filtros avanzados.
